# Little Lessons

Short, playful science lessons for young children, published with GitHub Pages.

Each lesson lives in its own folder with an `index.html`. To add a lesson, add a folder and a card in the root `index.html`.

- `day-night/`: Why do we have day and night? (K3, English voice-over)
- `seasons/`: Why does Hong Kong have four seasons? (K3, English voice-over)
